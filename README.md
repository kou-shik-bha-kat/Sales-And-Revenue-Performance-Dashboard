# Sales & Revenue Performance Dashboard

## 📊 Project Overview

An interactive Excel dashboard designed to analyze sales and revenue
performance and provide actionable business insights.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Dashboard Design

## 🔍 Key Analysis

- Revenue performance
- Sales trends
- Product/category performance
- Regional performance
- Customer/sales analysis
- Key performance indicators (KPIs)

The objective of this project is to transform sales data into an
interactive dashboard that helps stakeholders understand revenue
performance and identify important business trends.
